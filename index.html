How I build

From a question at home to a working app.

I'm a product person, not a full-time engineer. AI tools made the building part approachable too.

  1. 1

    Start with a real question

    Something my daughter asked, or something I never understood myself.

  2. 2

    Sketch the smallest version

    One page, plain language, pictures before words.

  3. 3

    Build it with AI

    Codex and Claude write the code with me. I decide what it should do and how it should feel.

  4. 4

    Use it, then fix it

    We try it at home. Whatever confuses us gets rebuilt.
